Maxim Toropov — Information Security Architect, 14+ years

I design and implement full-cycle information security systems for critical infrastructure, government and industrial control systems, from threat modeling to certification. I build tools that automate the regulatory part of that work.

ArtFSTEC is an open reference and threat-model builder for Russian FSTEC requirements: 227 threats from the national threat database, 245 controls across four regulatory orders, 143 attacker techniques, 64 classes of security tools, and a separate AI-threat catalog mapped to MITRE ATLAS. It generates a threat model and a technical design outline (Word / PDF). Built as a deterministic expert knowledge base — the catalog, not a language model, is the source of truth.

Stack: Python, Django, PostgreSQL. Current focus: security of AI/ML systems and applying LLMs to compliance workflows.
